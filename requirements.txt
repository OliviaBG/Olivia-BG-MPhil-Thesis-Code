#   Linux/WSL:     sudo apt-get install fpocket
#   macOS:         brew install fpocket
#
# There is no Windows build of fpocket -- run the structural pipeline under
# WSL. OpenMM does ship a Windows build, so a native-Windows environment can
# look complete while fpocket is missing.
#
# pocket_detector.py falls back to geometry-based pocket scoring if the
# fpocket binary is not on PATH, but the published CRM1 pocket-compatibility
# numbers were produced with fpocket installed. Verify with `fpocket -h`.
